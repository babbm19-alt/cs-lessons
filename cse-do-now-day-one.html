2 What you just did 1 MIN

Those four groups have names. You sorted them before anyone taught you what they were called.

Every program ever written — every app on your phone, every game you have played — is built out of these four ideas and nothing more exotic. You will spend this year learning to write them down precisely enough that a machine can follow them.

Step by step
Sequence
Instructions that run in order, one after another. Change the order and you change the result.
Depends on something
Selection
The program checks whether something is true, then picks a path. Often called an if statement.
Happens over and over
Repetition
The same instructions run again and again until a condition is met, or a set number of times. A loop.
Waits for a signal
Event
Nothing happens until something happens — a tap, a shake, a message arriving. Then the code runs.
