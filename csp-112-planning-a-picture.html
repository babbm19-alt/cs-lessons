Making a program interactive

Until now your turtle programs have done exactly the same thing every single time you ran them. That changes today.

An algorithm can be designed to accept information, called input. The program processes that input and produces output — the result. Giving the user choices is what makes a program feel personal instead of canned.

# This program takes input and produces output user_name = input("What is your name? ") print("Hello " + user_name)

The = is the assignment operator. The expression on the right is evaluated, and the result is stored in the variable on the left. It does not mean "equals" the way it does in math.

College Board connection. On the exam, assignment is written a ← expression, user input is INPUT(), and printing is DISPLAY(expression). Same ideas, different notation.

The circle method does more than circles

circle(r, e, s) takes up to three parameters:

  • r — the radius. Required.
  • e — the extent: how many degrees of the circle to draw. 180 gives a semicircle. Leave it out and you get the whole circle.
  • s — the steps: how many straight segments to draw it with. 5 steps makes a pentagon.

Order matters

Filling a shape with color

Three methods work together, and they only work in one order:

  • .fillcolor(c) — names the color to fill with. Must come first.
  • .begin_fill() — marks where the shape starts.
  • .end_fill() — marks where it ends, and fills it in.

Class vs object

📄 The blueprint and the thing

A class is a design — a blueprint or a recipe. An object is one actual thing built from that design, called an instance.

# Turtle is the CLASS — the blueprint # painter is the OBJECT — one turtle built from it painter = trtl.Turtle() artist = trtl.Turtle() # a second object from the same class

Objects have properties (characteristics — what it is) and methods (actions — what it does).

📝 Computer Science Notebook

  • Input is information given to a program; output is the result it produces.
  • The assignment operator = stores the value of the expression on the right into the variable on the left. College Board writes it a ← expression.
  • input() always returns a string, even if the user types a number. Use int() to convert it before doing math.
  • A substring is a part of an existing string.
  • Comments start with #. They are not executed — they make code readable for the next person.
  • circle(r, e, s): radius, extent in degrees, and number of steps. Steps turn a circle into a polygon.
  • fillcolor(c) then begin_fill() … shape … end_fill().
  • A class is the blueprint; an object is an instance built from it. Properties are characteristics, methods are actions.
