🎮 Gamertag Forge: Squad Edition

Your squad of three will build ONE program that forges a personal gamertag for every member, then fuses them into a squad name and a squad power level. It takes variables and operators from 1.1 and String methods from 1.2 — and it takes all three of you, because every member's name is raw material. One program, three forgers, one roster card at the end.

⏱ The plan — two class days

DAY 1 — forge the members (30 min)
0–5 minForm your squad, claim roles below, and agree on your forge recipe (or use ours).
5–10 minCopy the starter shell into ONE shared Trinket/VS Code. Run it before touching anything.
10–30 minEach member forges their own block: name variables, substring pieces, computed power, personal tag. Take turns at the keyboard — the coder rotates, the other two navigate.
DAY 2 — fuse the squad (30 min)
0–15 minForge the squad name from all three names and compute the squad stats (total, average, luck).
15–25 minBuild the full roster card, then run the Pre-Flight Check and fix anything amber.
25–30 minDemo for Mr. Babb: run it live, and each member explains the line they're proudest of.

🤝 Roles — everyone forges their own tag, and each member also owns one squad job

THE ARCHITECT
Owns the squad name: designs how pieces of all three names fuse into one, and keeps the program organized with comments so Mr. Babb can see whose block is whose.
THE QUARTERMASTER
Owns the math: the three power levels, the squad total, the average, and the luck stat. Checks every computed number by hand to prove Java got it right.
THE HERALD
Owns the roster card: designs the borders and layout, makes sure every tag and stat is concatenated in, and runs the demo on Day 2.

⚒ The forge recipe

Member tag (each of the three): first 3 letters of first name + first 2 letters of last name + power level
where power level = (firstName.length() + lastName.length()) * 3

Squad name: a substring piece of each member's first name, fused in order — e.g. first 3 letters of all three.
Squad stats: total = all three powers added · average = total / 3 · luck stat = total % 10
Your squad may invent its own recipe — as long as every member's name gets sliced with substring and every stat is computed, not typed.

📋 Requirements

Day 1 — the members

R1
All three members' names stored in String variables (6 Strings), each declared in that member's commented block: // ===== MEMBER 1: Jordan =====
R2
Each member's tag uses .substring() on both of their names (6+ substring calls total) and the squad uses .length() at least 3 times.
R3
Each member's power level is an int that Java computes with an operator from their name's .length() values — three computed ints, zero typed-in numbers.
R4
Each member's tag is built into its own String variable with concatenation — three tag variables.

Day 2 — the squad

R5
The squad name is one String variable fused from a substring piece of every member's name.
R6
The squad stats use at least two different operators: total power (addition), average (/), and luck stat (%). The Quartermaster verifies each number by hand.
R7
The roster card prints with at least 12 println statements: squad name, all three members with their tags, and all three squad stats concatenated in.
⭐
Stretch goals: add a random digit to the squad name with (int)(Math.random() * 10) · get the exact average with a cast: (double) total / 3 · put quotes inside your motto with the escape sequence \" · grow the card with +=.
